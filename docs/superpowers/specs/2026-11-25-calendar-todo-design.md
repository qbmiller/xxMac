# 日历与待办联动

用户已认可 `docs/design-previews/calendar-todo.html` 并要求实施。

- 月历下展示所选日截止的本地 Todo，默认今天，列表固定 182 pt 独立滚动。无截止日及已归档任务不混入日历；已完成任务默认隐藏，可切换显示。
- 日期用小点提示未完成事项。支持快速添加（所选日 18:00，可直接打开 Todo 修改）、完成/撤销、延期到明天（相对操作当日，保留原截止时间）、打开 Todo。
- 复用 TodoStore、todo.db、通知和 Widget 发布机制；不复制数据、不接 Apple 日历、不引入 RxSwift。
- 提供方向键日/周导航、Command 加左右键切月、Command-P 固定弹窗；文字编辑时不抢占按键。固定仅在本次打开期间有效。
- 支持 macOS 13、三种现有语言、深浅色和辅助功能。同步 README 与“通用 > 配置目录”说明。
- 参考 Calendr MIT 项目的交互，自行实现，不复制上游代码。
