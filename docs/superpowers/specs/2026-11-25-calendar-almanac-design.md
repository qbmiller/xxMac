# 日历黄历

用户已批准：日期右侧增加可点击的宜忌摘要，在整个日历左侧紧邻展示约 300pt 宽的黄历详情卡。使用现有材质、圆角、红色强调和细分隔线；完整宜忌、干支、冲煞、值神、吉神凶煞、等第、彭祖百忌可滚动查看。日期联动，展开状态仅当次会话有效。

cnlunar 固定提交 3f674fe0f458b480c79eaaf5464f43f4bc815a91，MIT。开发脚本按日、中午、上游默认算法生成按年压缩的离线数据与清单；Swift 查询，不启动 Python，不联网。覆盖以实际成功生成且农历年份有效的日期为准；范围外清楚显示暂无数据。

附属 NSPanel 统一处理屏幕边缘、置顶、外部点击、Escape 和父窗口关闭；普通日历窗口也支持。菜单栏 NSPopover 详情打开期间采用 applicationDefined，点击两者内不关闭。资源随 bundle_app.sh 打包。同步 README、配置目录说明和许可。
