# 输入法工具设计

用户已要求参考源码并直接实现上一轮的核心完整版。

- 新增输入法工具：通用、应用规则、网站规则、输入法提示、快捷键。
- 应用支持固定输入法、记忆用户选择、保持当前；全局默认保持当前，自动切换默认关闭。
- Chrome、Edge、Safari 网站规则支持精确域名、域名及子域名、URL 前缀；列表顺序决定优先级。地址栏优先于网站，网站优先于应用。离开地址栏恢复页面规则，页面无规则则恢复进入地址栏前的输入源。
- 提示支持输入源变化、应用切换、长按鼠标触发；位置、颜色、字号和时长可设置，不抢焦点。
- 快捷键支持指定单个输入源或在选定输入源间循环；共享快捷键冲突检测。允许独立暂停自动切换。
- 使用公开 TIS / Accessibility / NSWorkspace API，不引入上游的私有 API、辅助程序、Xcode 工程或依赖。浏览器 AX 查询在串行后台队列执行并校验当前进程和请求代次；只在前台浏览器需要规则时启用有界定时补查。
- 配置统一写入 preferences.json，加入导入导出、运行时目录迁移和三语资源；不会保存浏览历史或输入文本。
- 保留启动器英文设置，由统一切换入口执行并抑制自动切换被误记忆。
- 暂不实现纯修饰键、英文标点替换、F 键模式、常驻光标提示和终端内部程序识别。
