# Todo and Eisenhower Matrix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local SQLite-backed todo window with Eisenhower quadrants, list filters, a three-column status board, editable deadlines, local notifications, configurable `Command + Option + T`, archive/delete, search, sorting, and drag-and-drop.

**Architecture:** A feature-local model and policy layer feeds an isolated SQLite repository and a `@MainActor` observable store. A singleton AppKit window controller hosts focused SwiftUI views, while existing hotkey, settings, menu-bar, configuration-directory, and localization systems provide integration points.

**Tech Stack:** Swift 5.9, SwiftUI, AppKit, SQLite3, UserNotifications, HotKey, Swift Package Manager, XCTest.

**Spec:** `docs/superpowers/specs/2026-09-05-todo-design.md`

## Global Constraints

- Deployment target remains macOS 13.
- First release is local-only and must not implement CloudKit or place SQLite in iCloud Drive.
- New tasks default to `todo`, `notImportantNotUrgent`, and no deadline.
- Status rollback is fixed: `completed -> inProgress -> todo`; `todo` has no rollback.
- Four-quadrant ordering and status-board ordering are independent.
- Existing uncommitted README changes must be preserved.
- Use `swift test` and `swift build`; do not run `xcodebuild`.
- Commit each completed task without including unrelated worktree changes.
